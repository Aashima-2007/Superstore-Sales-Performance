# Superstore-Sales-Performance
Interactive Excel dashboard on 9,994 Superstore order lines (5,009 orders, 49 states, 2014-2017) using pivot tables, slicers, KPI cards and a US sales map. Finds that discounts over 20% drive losses, Furniture earns only a 2.5% margin and Tables lose money. Includes cleaning of mixed and swapped date formats.
